# Set up Shared Memory

Copy this into an agent with local file access. Ordinary note work does not require
this setup prompt again.

```text
Set up or update Shared Memory for my selected folder. Discover its existing
instructions, provider, project identity and private state; preserve them. Read
https://github.com/Kian-hdr/shared-memory/blob/main/docs/INSTALL.md
and use its verified release installation procedure. Do not execute unverified
packages or replace history, credentials or existing instructions.

Use native file tools for ordinary notes. New empty folders get Raw/, Wiki/,
Output/, AGENTS.md and INDEX.md; never reorganize a populated folder automatically.
Install a stable shared-memory command and automatic local capture when supported,
so routine edits require no model-generated script or manual sync. Verify capture
with a bounded edit/history check. Preserve prior runtime versions for rollback.

Keep the routine instructions short: read INDEX and relevant notes only, update
existing canonical Wiki pages, preserve evidence and uncertainty, and place generated
deliverables in Output. Keep setup/troubleshooting details out of routine context.

Retain conflict copies, explicit read-only limits and selected-folder boundaries.
Use one provider; local history is not proof of remote receipt. Formats 1/2 need
backed-up migration, not a new identity. Respect host authentication/OS controls.
If capture fails, preserve saved Markdown, report the exact error once and continue
feasible note work. Report the installed version, actual capture status and limits.
```
