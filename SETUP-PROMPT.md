# Set up Shared Memory

**A shared workspace for your team and its AI agents.** Obsidian is optional.

Copy this into a capable agent running on or connected to your computer. It will
find the actual project and reviewed package, and ask only for missing inputs.
This independent repository contains the Shared Memory development candidate.
Select a reviewed immutable revision and package. No stable release or
team readiness is implied by this prompt.

```text
Set up Shared Memory for my selected project folder, or join the existing project
whose owner supplied my setup instructions. Product source:
https://github.com/Kian-hdr/shared-memory

Carry out routine authorized local setup and verification. Discover my actual OS,
compatible Python, selected folder, create/join intent and storage method. A shared
subfolder inside my existing private Obsidian vault is a complete valid target.
Keep its parent, siblings and .obsidian settings private and unchanged. Do not create
or open an Obsidian vault or require a GUI for ordinary folder operation.

Obtain the exact reviewed runtime package and its external SHA-256 through the
approved source. Do not substitute latest main or an old published toolkit for an
unpublished product candidate. Read that version's README, operating guide,
capabilities and the target's existing instructions. Verify bytes before execution.
Use the authoritative init/attach workflow when the supplied package supports it;
do not silently bootstrap its older advisory tracker instead.

Reuse working local components. Install only missing compatible Python or optional
server dependencies within this setup authorization, preserving prior runtimes and
configuration. Routine steps do not need repeated confirmation. Respect my agent
and OS permission settings; protected sign-in/MFA/admin consent and missing essential
choices remain human interactions. Resume when resolved. Do not change accounts,
sharing permissions, send invitations/messages, publish, deploy or purchase without
that action's authorization.

Select private non-synchronized state outside the shared project for tokens,
connection settings, drafts, backups and coordinator SQLite. Local-only needs no
account or server. Team mode needs an actually reachable authorized coordinator;
provider choice does not grant access or deploy one. Discover the chosen provider's
actual client/folder or supported route. Keep provider access and coordinator
membership separate; never copy the sender's identity or device-local paths.

For a new owner project, initialize only the selected folder with my distinct human,
agent and actor identity. Preserve existing home/instructions and unrelated artifacts.
For joining, use my independently issued private token, the expected project ID and
verified coordinator endpoint; attach with my own folder and state directory. Do
not initialize, upgrade schemas or replace an owner's tracker while joining.
Legacy workspaces and interrupted setup require reviewed preservation/recovery.

Refresh accepted context, inspect team-status and verify receipt. Explain how my
agent claims bounded work, drafts with base revisions/evidence, submits for the
integration owner's acceptance, preserves conflicts and accepts handoffs only after
current receipt. Semantic review of prose remains necessary; timestamps/text merges
alone do not decide factual truth. Never delete drafts/history to make checks pass.

Report the exact runtime, project identity, actor, local receipt, coordinator access,
provider/account/OS support and unavailable checks separately. No local or simulated
result proves another device or cloud-provider receipt. Return a project-specific
teammate prompt in chat after owner setup, using real approved package/access
locators and no credentials or sender-local paths; do not send it automatically.

Do not migrate/restructure my live Vault or touch backup drives as part of onboarding.
Migration requires validated readiness, my independent backup/working-copy preparation
and explicit confirmation of the target. Finish authorized local work and identify
any remaining external gate precisely without calling incomplete team setup ready.
```
